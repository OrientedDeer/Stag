Add milestone-based triggers for dynamic retirement planning

Major feature: Users can define custom milestones (Coast FIRE, Debt Free, etc.)
with conditions like NET_WORTH >= 25x expenses, and link income/expenses to
start or end when milestones are reached.

Core System:
- AssumptionsContext: Add milestones array, BUILTIN_MILESTONE_IDS (BIRTH, RETIRE,
  END_OF_PLAN), helper functions (getBirthYear, getRetirementAge, getLifeExpectancy)
- SimulationEngine: Milestone evaluation each year, filtering income/expenses by
  milestone state, safety net for WorkIncome at retirement
- useSimulation: Pass milestone data through simulation
- MilestoneCalculator: Show actual retirement age from simulation events
- simulationHash: Include milestones for change detection

Models:
- Income/models.tsx: Add startMilestoneId, endMilestoneId to all income classes
- Expense/models.tsx: Add startMilestoneId, endMilestoneId to all expense classes
- Accounts/models.tsx: Updates for milestone support

New Files:
- src/services/simulation/ directory (types.ts, MilestoneEvaluator.ts, IncomeProjection.ts)
- MilestoneModal.tsx: UI for creating/editing milestones with condition builder
- TriggerSelector.tsx: Dropdown for selecting date or milestone trigger
- MilestoneEvaluator.test.ts, BrokerageLots.test.ts, IRAContributionLimits.test.ts,
  TaxOptimizedWithdrawals.test.ts

Income/Expense UI:
- AddIncomeModal: TriggerSelector for start/end, smart defaults (WorkIncome ends
  at RETIRE, pensions end at END_OF_PLAN)
- IncomeCard: Milestone trigger dropdowns
- AddExpenseModal: TriggerSelector for start/end
- ExpenseCard: Milestone trigger dropdowns

Services migrated to milestone-based demographics:
- TaxOptimizationService: Roth conversion windows, tax projections now use
  milestone-based retirement timing
- MonteCarloEngine: Years to run calculation
- ScenarioService: FI year calculation, retirement year
- ExcelExportService: Demographics export
- PDFReportService: Report data collection
- TaxService: Tax calculations

Tabs migrated:
- AssumptionTab: Milestone manager button
- FutureTab, OverviewTab, TaxOptimizationTab, FinancialRatiosTab
- WithdrawalTab, PriorityTab, CashflowTabs, HistoricalBacktestPanel
- AccountTab, TaxesTab, SpendingTab, Testing

Other:
- CustomDropdown: Portal rendering to fix modal clipping
- CurrencyInput: Don't show ($) when label is empty
- MilestoneModal: Wider layout (max-w-2xl), wider value input
- CashflowSankey, ScenarioCard: Minor updates
- qrUtils: Handle milestone fields in export

Bug Fixes:

- Show actual retirement age in Overview (not just AGE condition value)

Tests:
